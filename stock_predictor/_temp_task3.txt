步骤 1：数据层 —— 量化特征注入 (Quant Feature Injection)

**目标**：在送入神经网络之前，计算金融学金牌指标（布林带、RSI、MACD），并将它们作为特征拼接进原始 Tensor 中。

2. **极端反 NaN 措施**：计算滚动指标（Rolling）必定产生 `NaN`。必须使用 `ffill().bfill()` 或 `fillna(0.0)` 进行清洗。所有的无穷大（`inf`, `-inf`）必须被替换为最大阈值或 `0.0`。
3. **特征标准化**：像 RSI 这种天生在 0-100 之间的特征，需除以 100 缩放到 [0, 1] 区间。

**伪代码参考**：

```python
# 建议实现逻辑：
def add_quant_features(df):
    # 1. Bollinger Bands (布林带位置，反映超买超卖，0-1区间)
    df['MA20'] = df['close'].rolling(20).mean()
    df['STD20'] = df['close'].rolling(20).std()
    df['Upper'] = df['MA20'] + 2 * df['STD20']
    df['Lower'] = df['MA20'] - 2 * df['STD20']
    df['BB_Pos'] = (df['close'] - df['Lower']) / (df['Upper'] - df['Lower'] + 1e-8)
    
    # 2. RSI (相对强弱指标)
    delta = df['close'].diff()
    up = delta.clip(lower=0)
    down = -1 * delta.clip(upper=0)
    ema_up = up.ewm(com=13, adjust=False).mean()
    ema_down = down.ewm(com=13, adjust=False).mean()
    rs = ema_up / (ema_down + 1e-8)
    df['RSI'] = (100 - (100 / (1 + rs))) / 100.0 # 缩放到0-1
    
    # 3. 极端的 NaN 和 Inf 清洗 (防止 PyTorch 梯度爆炸)
    df.replace([np.inf, -np.inf], np.nan, inplace=True)
    df = df.bfill().ffill().fillna(0.0)
    return df

```

### 步骤 2：模型层 —— 残差架构重构 (Residual Modeling)

**目标**：不让深度学习直接预测“明天的绝对价格”，而是让它预测“传统基准公式的残差”。

**开发要求（请 Claude 实现）**：

1. 选取一个极其稳健的量化基准（Baseline），例如“昨日收盘价”或“20日均线（MA20）”。
2. 修改 `HybridModel` 的输出逻辑。模型的网络部分输出的不再是 `pred_price`，而是 `price_delta`（涨跌偏差）。
3. 最终的预测输出为：$P_{final} = P_{baseline} + P_{delta}$。

**伪代码参考**：

```python
import torch
import torch.nn as nn

class ResidualQuantModel(nn.Module):
    def __init__(self, existing_hybrid_model):
        super().__init__()
        # 复用我们现有的深度学习提取器
        self.dl_core = existing_hybrid_model 
        
    def forward(self, x, baseline_price):
        """
        x: [batch, seq_len, features]
        baseline_price: [batch, 1] 比如当天的 MA20 或者昨日收盘价
        """
        # DL模型现在只负责预测波动的“残差”
        residual = self.dl_core(x) 
        
        # 最终预测 = 确定性基准 + AI捕捉的非线性残差
        final_pred = baseline_price + residual
        return final_pred, residual

```

### 步骤 3：损失层 —— 稳健防爆的 PINN Loss (Stable Financial PINN)

**目标**：引入布林带等量化边界作为常识惩罚项。**为了防止梯度爆炸，绝对不能直接使用原始差异，必须使用 `SmoothL1Loss` (Huber Loss) 或对数惩罚。**

**开发要求（请 Claude 实现）**：

1. 编写自定义 `QuantPINNLoss`。
2. 基础 Loss 使用 `MSE` 或 `HuberLoss`。
3. 边界惩罚使用防爆设计：如果预测价格突破布林带上下轨，计算越界距离 $d$。惩罚项设为 $\log(1 + d)$ 或 $SmoothL1(d)$，坚决避免平方项引起数值爆炸。
4. 惩罚权重 $\lambda$ （lambda）设为可配置参数，建议初始默认值为 0.1。

**伪代码参考**：

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class StableQuantPINNLoss(nn.Module):
    def __init__(self, lambda_quant=0.1):
        super().__init__()
        # 使用 SmoothL1Loss 替代 MSE，天生防梯度爆炸
        self.base_loss_fn = nn.SmoothL1Loss() 
        self.lambda_quant = lambda_quant

    def forward(self, pred_price, target_price, upper_band, lower_band):
        # 1. 基础回归误差
        base_loss = self.base_loss_fn(pred_price, target_price)
        
        # 2. 计算违规溢出量 (越出上轨或跌破下轨)
        # 使用 F.relu 提取超出边界的部分，没超出就是 0
        violation_upper = F.relu(pred_price - upper_band)
        violation_lower = F.relu(lower_band - pred_price)
        total_violation = violation_upper + violation_lower
        
        # 3. 防爆惩罚计算 (Log1p: ln(1+x))
        # 极其重要：传统平方惩罚在股票数据上极易导致梯度爆炸，这里用 log 平滑
        quant_penalty = torch.mean(torch.log1p(total_violation))
        
        # 4. 总 Loss
        return base_loss + self.lambda_quant * quant_penalty

```
