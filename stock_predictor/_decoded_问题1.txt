在 Claude Code 中，首先添加市场：

/plugin marketplace add forrestchang/andrej-karpathy-skills
然后安装插件：

/plugin install andrej-karpathy-skills@karpathy-skills
这会将指南安装为 Claude Code 插件，使这项技能在所有项目中都能使用。
如何判断它是否有效
如果你看到以下情况，这些指南是有效的：

差异中不必要的更改更少——只显示请求的更改
由于过于复杂，重写次数减少——代码第一次写起来很简单
澄清性问题应在实施之前出现——而非错误之后
干净、最低限度的PR——没有盲目重构或“改进”
定制化
这些指南设计为与项目特定的说明合并。把它们添加到现有的，或者创建一个新的。CLAUDE.md

针对项目特定规则，添加以下部分：

## Project-Specific Guidelines

- Use TypeScript strict mode
- All API endpoints must have tests
- Follow the existing error handling patterns in `src/utils/errors.ts`
权衡备注
这些指南偏向谨慎而非速度。对于琐碎的任务（简单的拼写修正、明显的一句台词），请用判断力——并非每个改动都需要完全严谨。

目标是减少非简单工作中代价高昂的错误，而不是拖慢简单任务的速度。
